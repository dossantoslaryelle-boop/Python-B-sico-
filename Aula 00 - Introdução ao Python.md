# 📘 Introdução à Linguagem Python

## 🎯 Objetivo
Este repositório tem como objetivo servir como material de estudo sobre os conceitos iniciais da linguagem Python, apresentando explicações claras, organizadas e de fácil compreensão.

---

## 🧠 1. O que é Python

Python é uma linguagem de programação:

- De alto nível  
- Interpretada  
- Multiplataforma  
- De propósito geral  

**Diferencial:** Possui sintaxe simples e legível, facilitando o aprendizado e o desenvolvimento.

### 📌 Principais usos:
- Desenvolvimento web  
- Automação de tarefas  
- Ciência de dados  
- Inteligência artificial e Machine Learning  
- Computação científica  
- Ensino de programação  

---

## 📜 2. Histórico do Python

- Criado no final dos anos 1980 por **Guido van Rossum**
- Desenvolvido no instituto **CWI (Holanda)**
- Primeira versão: **Python 0.9.0 (1991)**

O nome *Python* vem do grupo humorístico **Monty Python**, e não da cobra.

### 🚀 Marco importante:
- **Python 3.0 (2008)** → versão moderna com melhorias significativas
